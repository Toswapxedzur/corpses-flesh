# Corpses Flesh

A Minecraft 1.21.1 NeoForge addon that stops corpse entities from blocking block placement.

## Compatibility

- Minecraft 1.21.1
- NeoForge
- Corpse 1.0.3 or newer

## Development

Use JDK 21, then run:

```sh
./gradlew build
```

Local Gradle caches, IDE settings, and Minecraft test-world output are intentionally ignored by Git.
